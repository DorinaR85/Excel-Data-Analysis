# Excel Data Analysis – Sales & Orders Dashboard

## Project Overview
This Excel project focuses on analyzing sales and order data across different markets and regions, using Microsoft Excel to organize, summarize, and visualize business information.

## Tools & Techniques
- Microsoft Excel
- Pivot Tables
- Data visualization and charts
- Data organization and analysis
- Interactive dashboard and reporting

## Project Contents
- Sales and orders dataset
- Market and region analysis
- Pivot Tables for data summarization
- Dashboard and scoreboard
- Business analysis questions and visual reports

## Project Objective
The objective is to transform sales and order data into clear, meaningful insights that support business reporting and data-driven decision-making.

## Files
- `Unit Summary Project_Part2.xlsx` – Excel workbook containing the dataset, analysis, Pivot Tables, charts, and dashboard.
